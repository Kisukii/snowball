# Source samples for evaluation
These are selected source files, not complete runnable applications. They have not been integrated into Snowball or runtime-tested here.

See ../similar-projects-2026-10-25.md for findings and sources.json for exact source URLs and revisions.

- clicky-windows: MIT source samples from Bitshank-2338/clicky-windows, preserving its LICENSE and the original Clicky MIT notice. PyQt6 is separately GPL/commercial licensed.
- nanobrowser: Apache-2.0 source samples. The TypeScript files depend on the rest of the upstream browser-control subsystem.

No installers were run and no dependencies were installed.
